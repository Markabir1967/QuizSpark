QUIZSPARK — ANDROID APP PROJECT

Features
- Colorful quiz home screen and topic cards
- 9 topic choices plus All Topics
- Randomized rounds (up to 10 questions)
- Multiple-choice questions with explanations
- Score, streak, progress indicator and saved best score
- Results screen and replay
- Offline; no account or internet permission required

BUILD AN APK (Windows)
1. Install Android Studio from https://developer.android.com/studio
2. Open Android Studio and choose Open, then select the extracted QuizSpark folder.
3. Allow Gradle sync. If prompted, install Android SDK Platform 35 and Android SDK Build-Tools using SDK Manager.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. When build finishes, click Locate. The APK should be at app/build/outputs/apk/debug/app-debug.apk.
6. Transfer app-debug.apk to your Android phone and open it. If asked, allow installation from that source.

REQUIREMENTS
- Android Studio with Android SDK Platform 35
- JDK 17 or newer (Android Studio bundles a compatible runtime)
- Internet access during the first Gradle dependency sync

Note: This environment does not have Flutter, Gradle, or an Android SDK installed, and external downloads are unavailable here, so I could not compile or verify an APK in this session. This ZIP is a complete Android Studio project, not an APK binary.
